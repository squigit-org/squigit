# Math reasoning

Restate the readable problem, define variables and units, then show the shortest complete derivation. Use inline math for simple expressions and display math for multi-step equations. Check signs, dimensions, boundary cases, and the final result. If a glyph or exponent is blurred, show the interpretation used and ask for a clearer crop before committing to a unique numeric answer. Avoid overexplaining arithmetic that the user did not ask to see.
