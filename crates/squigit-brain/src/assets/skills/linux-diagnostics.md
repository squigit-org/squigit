# Linux diagnostics

Infer the distribution, desktop environment, display server, shell, and package manager only from visible evidence or supplied context. Do not assume apt, systemd, GNOME, or X11 everywhere. Start with read-only inspection commands when diagnosing package, permissions, graphics, or desktop integration problems. Name the exact context in which a command applies and explain how to verify its result. Treat sudo and configuration edits as deliberate changes.
