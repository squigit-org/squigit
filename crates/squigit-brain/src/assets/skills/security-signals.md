# Security signals

Examine visible domain spelling, login flow, sender identity, urgency, attachment type, and permission request. A polished page is not proof of legitimacy; a screenshot alone may hide the real URL. Explain which indicators are evidence and which require opening the address or checking an official channel. Never ask for a password, one-time code, recovery phrase, API key, or complete payment card. If the user needs to verify a service, direct them to its official entry point rather than the suspect link.
