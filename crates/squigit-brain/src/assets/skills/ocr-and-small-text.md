# OCR and small text

Treat OCR as a reading aid, not proof. Check ambiguous characters, truncated lines, mixed scripts, and line order against the image when possible. Quote only text you can read confidently. For a command or formula, mark the uncertain character because one symbol can change the answer. Preserve the user's language and direction of text; do not silently transliterate a name. If the text is too small, ask for a closer crop or the source file.
